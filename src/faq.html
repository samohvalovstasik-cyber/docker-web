Часто задаваемые вопросы

Ответы на самые популярные вопросы, которые возникают у новичков в Docker.

Чем контейнер отличается от образа?

Образ — это неизменяемый шаблон, содержащий приложение и его зависимости. Контейнер — запущенный экземпляр образа. Можно запустить сколько угодно контейнеров из одного образа.

Зачем нужен .dockerignore?

Файл .dockerignore исключает ненужные файлы (например, node_modules, .git, dist) из контекста сборки. Это ускоряет сборку и уменьшает размер образа.

Как работают тома (volumes)?

Тома — это специальные хранилища, которые живут отдельно от контейнера. Данные в томах сохраняются даже при удалении контейнера. Это критично для баз данных.

Docker бесплатный?

Docker Engine — полностью open source и бесплатен. Docker Desktop бесплатен для личного использования, образования и малого бизнеса, но требует платной лицензии для крупных компаний.

Можно ли запустить Docker без Docker Desktop?

Да. На Linux достаточно установить Docker Engine и docker compose plugin. На Windows и macOS Docker Desktop — самый простой вариант, но существуют и альтернативы (Podman, Rancher Desktop).

Чем контейнер отличается от виртуальной машины?

Контейнеры используют ядро хост-системы и изолируют только процесс. Виртуальные машины эмулируют полноценное железо и запускают своё ядро. Поэтому контейнеры в разы легче и быстрее.

Как передать данные внутрь контейнера?

Три способа: COPY в Dockerfile (на этапе сборки), монтирование volume (для постоянных данных), переменные окружения -e KEY=value (для конфигурации).

Безопасно ли запускать контейнеры из интернета?

Не всегда. Используйте официальные образы, регулярно обновляйте их, сканируйте на уязвимости (docker scout), не запускайте от root и ограничивайте capabilities.
