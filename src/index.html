Docker Compose

Оркестрация нескольких контейнеров в одном файле.

Пример базового Dockerfile

Ниже — минимальный пример Dockerfile для статического сайта на Nginx:

FROM nginx:alpine
COPY ./dist /usr/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]

Преимущества контейнеризации

  • Изоляция: каждое приложение работает в своём окружении.
  • Воспроизводимость: одинаковый результат на любых машинах.
  • Портативность: образ работает везде, где установлен Docker.
  • Скорость: запуск контейнера занимает секунды.
