Написание Dockerfile

Dockerfile — это текстовый файл с инструкциями для сборки образа. Он описывает, какой базовый образ использовать, какие файлы скопировать и какие команды выполнить.

Пример для статического сайта

Классическая multi-stage сборка: сначала собираем проект на Node.js, потом отдаём готовые файлы через Nginx.

FROM node:20-alpine AS build
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=build /app/dist /usr/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]

Основные инструкции

Инструкция Назначение
FROMБазовый образ, от которого наследуемся
WORKDIRУстанавливает рабочую директорию внутри контейнера
COPYКопирует файлы с хоста в образ
RUNВыполняет команду при сборке образа
EXPOSEОбъявляет порт, который слушает приложение
CMDКоманда по умолчанию при запуске контейнера
ENVЗадаёт переменные окружения
ARGАргументы сборки, доступные только в момент build

Сборка и запуск

docker build -t my-site .
docker run -d -p 8080:80 my-site

⚠️ Совет: всегда создавайте файл .dockerignore рядом с Dockerfile — он исключает ненужные файлы (node_modules, .git, dist) из контекста сборки и ускоряет её в разы.
