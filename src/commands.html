Основные команды Docker

Эти команды покрывают 90% повседневной работы с Docker. Сохраните страницу в закладки — пригодится при первом запуске контейнеров.

Работа с контейнерами

Управление жизненным циклом контейнеров
Команда Назначение
docker psСписок запущенных контейнеров
docker ps -aВсе контейнеры, включая остановленные
docker run -d -p 8080:80 nginxЗапустить nginx в фоне, порт 8080 хоста → 80 контейнера
docker stop <id>Остановить контейнер
docker start <id>Запустить остановленный контейнер
docker restart <id>Перезапустить контейнер
docker rm <id>Удалить контейнер
docker logs -f <id>Логи контейнера в реальном времени
docker exec -it <id> bashВойти в контейнер (интерактивная оболочка)

Работа с образами

docker images                     # список локальных образов
docker pull nginx:alpine          # скачать образ
docker build -t my-app .          # собрать образ из Dockerfile
docker push myuser/my-app:1.0     # отправить образ в реестр
docker rmi nginx:alpine           # удалить образ

Работа с томами и сетями

docker volume create mydata       # создать том
docker volume ls                  # список томов
docker volume rm mydata           # удалить том

docker network create mynet       # создать сеть
docker network ls                 # список сетей
docker network inspect mynet      # детали сети

Очистка системы

Эти команды удаляют неиспользуемые контейнеры, образы, тома и сети — помогают освободить диск:

docker system df                  # сколько места занимает Docker
docker system prune               # удалить остановленные контейнеры и висячие образы
docker system prune -a --volumes  # глубокая очистка (осторожно!)

⚠️ Будьте осторожны: команда docker system prune -a --volumes удалит все неиспользуемые образы, контейнеры и тома. Данные из томов восстановить будет нельзя.

Полезные сокращения

  • docker container ls = docker ps
  • docker image ls = docker images
  • docker-compose up = docker compose up (в новых версиях)
