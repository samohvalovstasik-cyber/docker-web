Установка Docker

Docker Desktop доступен для Windows, macOS и Linux. Ниже — пошаговая инструкция, которая поможет установить и проверить работу Docker на вашем компьютере.

Шаг 1. Скачать установщик

Перейдите на официальный сайт docker.com и скачайте версию для вашей операционной системы:

  • Windows — Docker Desktop for Windows (требуется WSL 2 или Hyper-V).
  • macOS — Docker Desktop for Mac (Intel или Apple Silicon).
  • Linux — Docker Engine через пакетный менеджер дистрибутива.

Шаг 2. Установить

Для Windows и macOS

Запустите скачанный установщик и следуйте инструкциям мастера установки. После завершения установки перезагрузите компьютер и запустите Docker Desktop из меню «Пуск» (или из Launchpad).

Для Linux (Ubuntu / Debian)

Выполните в терминале следующие команды:

sudo apt update
sudo apt install docker.io docker-compose-plugin
sudo systemctl enable --now docker

Шаг 3. Проверить установку

Откройте терминал и выполните:

docker --version
# Ожидаемый вывод: Docker version 26.1.0, build ...

docker run hello-world
# Ожидаемый вывод: Hello from Docker!

Если вы увидели сообщение «Hello from Docker!» — установка прошла успешно.

⚠️ Важно для Linux: чтобы запускать Docker без sudo, добавьте своего пользователя в группу docker: 

sudo usermod -aG docker $USER

После этого выйдите из системы и войдите снова.
