Примеры проектов

Несколько типовых сценариев, с которыми вы столкнётесь в реальной веб-разработке.

🌐 Статический сайт на Nginx

Сборка HTML/CSS/JS и отдача через Nginx. Multi-stage сборка уменьшает итоговый образ до ~25 МБ.

FROM nginx:alpine
COPY ./dist /usr/share/nginx/html

⚛️ React + Vite

SPA с горячей перезагрузкой внутри контейнера. Монтирование исходников через volume.

FROM node:20-alpine
WORKDIR /app
CMD ["npm", "run", "dev"]

🐘 PHP + MySQL

Классический LAMP-стек: веб-сервер Apache + PHP + база MySQL в одном compose-файле.

services:
  web:
    image: php:8.3-apache
  db:
    image: mysql:8

🐍 Django + Postgres

Python-приложение с миграциями, статикой и базой данных. Отдельный контейнер для Celery.

services:
  web:
    build: .
    command: python manage.py runserver
